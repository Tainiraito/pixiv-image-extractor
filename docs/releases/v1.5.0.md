## 简体中文

新增简体中文和英语界面，以及下载后自动关闭弹窗的设置。以下变更相对 v1.4.0。

### 新增

- 设置中的「语言 / Language」支持「简体中文」和「English」，切换即时生效并保存。
- 未设置偏好时按浏览器界面语言选择；英语变体使用英语，未支持或未知语言回退中文。
- 任务进度、历史摘要、操作按钮和错误提示随界面语言更新。切换不会中断下载或改变图片选择。
- 新增「下载后自动关闭弹窗」，默认开启；逐张或打包任务成功启动后关闭弹窗，后台继续下载，启动失败时保留错误提示。可在设置中关闭。

### 升级说明

Chrome 最低版本仍为 116，不新增权限。原有任务记录与下载设置保留；作品信息、文件名模板及部分外部或历史错误详情保留原文。

### 安装与更新

[下载安装包](https://github.com/Tainiraito/pixiv-image-extractor/releases/download/v1.5.0/pixiv-image-extractor-v1.5.0.zip)，解压后在 Chrome 扩展管理页开启开发者模式，加载包含 `manifest.json` 的 `pixiv-image-extractor` 文件夹。

更新时覆盖原扩展目录中的文件，点击「重新加载」，再刷新 Pixiv 页面。下载后自动关闭弹窗默认开启，可在设置中关闭。

[完整变更：v1.4.0 → v1.5.0](https://github.com/Tainiraito/pixiv-image-extractor/compare/v1.4.0...v1.5.0)

## English

Adds Simplified Chinese and English interfaces and automatic popup closing after starting a download. Changes below are relative to v1.4.0.

### Added

- **语言 / Language** in settings offers **简体中文** and **English**. Changes apply immediately and are saved.
- With no manual preference, the browser UI language selects the default. English variants use English; unsupported or unknown languages fall back to Chinese.
- Task progress, history summaries, controls, and error messages follow the interface language. Switching preserves downloads and image selection.
- Added **Close popup after starting a download**, enabled by default. The popup closes after an image or ZIP task starts, while background downloads continue. Startup errors remain visible. Disable it in settings to keep the popup open.

### Upgrade notes

Chrome 116 remains the minimum, with no new permissions. Existing task records and download settings are retained. Artwork metadata, filename templates, and some external or historical error details retain their original language.

### Install and update

[Download the installation package](https://github.com/Tainiraito/pixiv-image-extractor/releases/download/v1.5.0/pixiv-image-extractor-v1.5.0.zip), extract it, enable Developer mode on Chrome's extensions page, and load the `pixiv-image-extractor` folder containing `manifest.json`.

To update, replace the files in the existing extension folder, click **Reload**, and refresh Pixiv pages. Automatic popup closing is enabled by default; disable it in settings to keep the popup open.
