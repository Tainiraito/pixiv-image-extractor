# Pixiv 图片提取 v1.4.0

从 Pixiv 作品页面提取高清图片，支持预览、勾选、后台下载和自动分卷打包。

## v1.4.0 更新

- 新增本地任务历史、暂停/继续与仅补未完成部分的重试，最多保留 50 条记录并自动清理最早完成的记录
- 首页预览最多三条未完成任务，顶部入口查看完整历史，任务卡片精简为两行
- 缩略图默认三行，超过九张可展开全部，折叠不影响选择
- 作品信息与入口吸顶，下载设置集中到齿轮入口，ZIP 张数支持步进 1 的滑块
- 更新下载按钮文案，统一简约滚动条，任务列表弹窗仅内容区域滚动

## 功能

- 🖼️ 自动识别作品页面所有图片
- ✅ 三行缩略图预览，超过 9 张可展开全部，收起时保留选择
- 📥 逐张下载选中的高清原图
- 📦 大型画廊自动分卷打包
- 📋 下载任务列表：独立进度、暂停继续、失败重试与手动移除
- 📝 自定义下载文件名模板（支持占位符）
- 🎨 浅色主题 UI，搭配细圆角滚动条与透明轨道

## 安装

1. 下载本项目到本地
2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择 `pixiv-image-extractor` 文件夹

## 使用

1. 打开 [Pixiv](https://www.pixiv.net/) 任意作品详情页（如 `pixiv.net/artworks/116299462`）
2. 点击浏览器工具栏中的扩展图标
3. 图片会自动提取并显示预览网格；超过 9 张时，第九格显示模糊九宫格和「查看全部 x 张」，点击展开所有图片，可再点击「收起图片」
4. 点击图片勾选/取消，或使用「全选」按钮
5. 可选：点击顶部齿轮设置文件名模板与 ZIP 每卷最多图片数；张数滑块支持左右拖动或方向键调整，范围 1～100、步进 1，设置自动保存
6. 点击「下载」保存原图（选中多张时显示「逐张下载」），或点击「打包下载」生成 ZIP（预计多卷时显示「分卷下载」）
7. 下方「下载任务」最多显示三条未完成任务，超过三条可点右侧数量查看全部；顶部任务列表图标（齿轮旁）显示所有记录，可以切换标签页或关闭弹窗，重新打开后记录仍在
8. 顶部作品名称、作者、图片数量与任务列表/设置入口固定吸顶，滚动图片时仍可访问

## 下载任务管理

- 每次下载或打包生成一条两行记录：第一行显示作品与状态，第二行显示类型、进度、分卷数/失败数及可用操作，底部细条显示进度；悬停进度文字可查看具体处理信息
- 首页仅预览三条未完成任务，进行中的任务优先显示；成功完成后自动从预览移到顶部入口的任务列表，部分失败任务保留在预览中以便重试
- 任务列表弹窗的标题与关闭按钮固定，仅记录区域滚动；弹窗随可用高度缩小，避免双层滚动条
- 同时执行一个任务；暂停或停止当前任务后，可创建其他任务
- 「暂停」停止获取后续图片，并暂停正在写盘的 Chrome 下载；「继续」保留原任务，跳过已成功保存的图片或 ZIP 卷
- 未提交的 ZIP 卷会在继续时重新打包，已保存的卷不会重复下载
- 失败或部分失败的任务可「重试」，只补未成功的图片或卷；停止后的任务也可重试
- 已结束的任务可用右上角 × 移除记录，不会删除下载文件；进行中和暂停的任务需先停止
- 记录和续传检查点保存在本机扩展存储中，关闭弹窗、重启后台或浏览器后仍可查看。浏览器重启造成中断时，可重试未完成部分
- 最多保留 50 条任务记录；创建新任务达到上限时，自动清理最早成功完成的记录，不删除下载文件。暂停、失败、部分失败的记录不会被自动清理；没有可清理的已完成记录时，需要先手动移除已结束的记录

## 大型画廊与 ZIP 分卷

- 普通下载逐张获取并交给 Chrome 下载管理器，每次只在内存中保留一张原图
- ZIP 每卷张数可在顶部设置中调整，默认值和范围统一由 `config.js` 管理
- 即使尚未达到图片数量上限，当前卷达到配置的容量上限时也会自动提前切卷
- 多卷文件使用 `_part001.zip`、`_part002.zip` 格式命名
- 下载与打包由后台隐藏文档执行，不依赖弹窗和当前标签页持续打开
- 「停止后台任务」只停止后续处理，已经加入 Chrome 下载队列的任务会继续执行
- 即使 Chrome 下载已暂停，也能停止后台处理并开始新任务；旧下载需要的 Blob 会保留到下载完成或中断，新任务复用隐藏文档
- 暂停的旧下载会继续占用相应图片或 ZIP 的内存，可在下载管理器中恢复或取消来释放资源

## 文件名模板

在下载前可自定义文件名格式，支持以下占位符：

| 占位符 | 含义 | 示例 |
|--------|------|------|
| `{id}` | 作品 ID | 116299462 |
| `{author}` | 作者名 | 鸦居 |
| `{title}` | 作品标题 | 星妲 |
| `{index}` | 页码 | 1 |

默认模板：`pixiv_{id}_{author}_{title}_p{index}`

示例：`{author}-{title}-p{index}` → `鸦居-星妲-p1.jpg`

## 技术实现

- **提取策略**：调用 Pixiv 内部 API `/ajax/illust/{id}/pages` 获取所有图片 URL
- **后台架构**：Service Worker 调度任务，通过 `chrome.storage.local` 保存任务历史和续传检查点；兼容旧版 session 进度记录
- **任务状态**：启动、恢复、取消、进度写入及清理按同一队列串行处理；执行器就绪前使用 `starting` 状态
- **持续执行**：Offscreen Document 负责获取图片、生成 ZIP 和管理 Blob 生命周期
- **停止与清理**：停止后台处理与监控已提交下载分别执行；仅在无任务且无未完成下载时关闭隐藏文档
- **Referer 处理**：通过 `declarativeNetRequest` 规则自动为 i.pximg.net 请求添加 Referer 头
- **预览**：使用 regular 尺寸图片（master1200，约 1200px 宽）
- **下载**：后台逐张获取 original 原图并转换为同源 Blob，再交给 `chrome.downloads`
- **打包下载**：使用 JSZip 的 STORE 模式分卷生成 ZIP，避免对已压缩图片重复压缩
- **内存控制**：每个 ZIP 同时受 `config.js` 中的图片数量与容量配置限制

## 适配范围

- Chrome 116+（使用 Offscreen Document 和 `runtime.getContexts()`）
- Pixiv 作品详情页 `https://www.pixiv.net/artworks/*`

## 已知限制

- 需要 Pixiv 登录状态才能调用 API
- 下载保存到 Chrome 默认下载目录
- Ugoira（动图）暂不支持，会作为普通图片处理

## 本地回归测试

测试使用 Node.js 内置测试运行器，无需安装 npm 依赖。两个 VM 加载真实后台和隐藏文档脚本，模拟 Chrome API 与图片响应；ZIP 测试使用项目自带的 JSZip 并检查解包内容。

```powershell
node --test tests/download-lifecycle.test.cjs
```

若环境禁止测试运行器创建子进程，可使用 Node.js 24 的 `node --test --test-isolation=none tests/download-lifecycle.test.cjs`。

19 项测试覆盖记录上限自动清理与保护未完成任务、并发启动、启动期间恢复、worker 重启、任务历史与移除、暂停继续、只重试失败图片、ZIP 分卷续传、旧 Blob 与新任务共存和下载中断等路径。这些回归测试不替代真实浏览器与 Pixiv 登录环境的验证。
